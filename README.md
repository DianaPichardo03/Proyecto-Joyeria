# 💎 Joyería Diana - Ecommerce Fullstack

Aplicación web fullstack para venta de joyería desarrollada con **React, Node.js, Express y MySQL**.

El sistema incluye una tienda online para clientes y un panel administrativo para gestión de productos y pedidos.

---

# 🚀 Demo

Frontend:
https://proyecto-joyeria.vercel.app

Backend API:
https://proyecto-joyeria-50z0.onrender.com

---

# ✨ Características

## 🛍️ Cliente

* Visualización de productos
* Carrito de compras
* Control de stock
* Simulación de pago
* Envío de pedido por WhatsApp
* Modo oscuro
* Diseño responsive

## 👨‍💼 Administrador

* Login protegido
* Panel administrativo
* Agregar productos
* Editar productos
* Eliminar productos
* Gestión de pedidos
* Marcar pedidos como entregados
* Subida de imágenes

# ⚙️ Instalación local

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/DianaPichardo03/Proyecto-Joyeria.git
```

---

# 🖥️ Frontend

```bash
cd frontend
npm install
npm run dev
```

---

# 🔧 Backend

```bash
cd backend
npm install
npm run dev
```

---

# 🗄️ Variables de entorno

Crear un archivo `.env` en el backend:

```env
DB_HOST=tu_host
DB_USER=tu_usuario
DB_PASSWORD=tu_password
DB_NAME=tu_base_de_datos
DB_PORT=tu_puerto
```

---

# 🗃️ Base de datos

Importar el archivo:

broqueles.sql
